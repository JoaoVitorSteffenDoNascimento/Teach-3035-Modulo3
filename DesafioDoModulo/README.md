# Desafio do Módulo

Este diretório contém o projeto Java `DesafioDoModulo.java`, um jogo de adivinhação no terminal com:

- níveis de dificuldade (Fácil, Médio e Difícil);
- modo normal e modo sequência;
- sistema de pontuação;
- histórico das últimas partidas;
- recordes por modo e dificuldade.

## Como executar

1. Compile o arquivo:
   ```bash
   javac DesafioDoModulo.java
   ```
2. Execute o programa:
   ```bash
   java DesafioDoModulo
   ```
